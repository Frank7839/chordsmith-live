Songs

List the sections in the order you play them, repeats included. Write chords inside the lyrics in brackets, like [G]Amazing [C]grace, or on their own line, like [G] [D] [Em] [C]. Bars set when the guide calls the next section.

Band room

Lead the band

Start a room on the device that runs the click and guide. Everyone who joins sees the same setlist, the key you choose, and where you are in the song.

Join a band

Enter the code on the leader’s screen, or scan their QR code.

Works best when everyone is on the same Wi-Fi or one phone’s hotspot. On mobile data some networks block direct connections between phones.

Settings

My chart

These are just for this device, so each player can read the chart their own way.

In-ear guide

Runs on the leader’s device. Counts the band in, calls each section a bar early, and speaks the calls you tap on stage. Route this device to your in-ear mix.

Voice clips

Uses the same voice as Chordsmith Studio: clips you loaded there show up here automatically. Missing words use the phone’s built-in voice, which can land a little late.

Backup

Songs and setlists are saved only on this device. Export a backup file, or move everything to another phone.
